v0.5 · Event-sourced tracker + reality check + profile audit + look-alike analysis · Print and keep at your desk

How It Works · Daily Rhythm

Events is the source of truth (append-only). Applications is a state view derived from it. Every action writes an Event. Lose Applications → rebuild from Events. Lose Events → lose history.

Daily flow: 7 AM discovery runs auto · morning check Dashboard + triage Found rows · prepare 3-5 apps · review tabs + submit yourself · evening Gmail sweep updates statuses.

Recurring Commands (use daily / weekly)

1. Run discovery nowRun my daily job search. Run all active Saved Searches against listed boards via Chrome. Score, dedupe, write new rows + Discovery Found events. Write a snapshot per search/board to Market Snapshots.
2. Prepare applicationsTake the top 5 Found rows. Open each in Chrome, fill from my job-profile, draft a tailored cover letter. Stop before Submit. Set status to Drafted, write Status Changed events, save app URLs in Notes.
3. Check for connectionsFor any Drafted/Submitted row, check LinkedIn for 1st-degree connections at the company. Draft referral DMs in the compose window. Do not send. Write Outreach Drafted events.
4. Daily summarySummarize my pipeline from Dashboard. Counts, anything Drafted >3 days, Submitted >14 biz days silent, interviews this week.
5. Email sweepCheck Gmail for ATS confirmations, recruiter replies, interview invites, rejections from last 24 hours. Write Email Received events. Update status when unambiguous; flag ambiguous ones.
6. Reality check (weekly)Run a reality check on my searches. Use reality-check skill. Flag unrealistic configs, profile mismatches, or stuck patterns. Suggest pivots where data supports. Write a Reality Check event.

Occasional Commands (monthly / quarterly)

7. Market trend checkShow market trend for [search name] over last 8 weeks. Plot weekly Total Results, compute slope, name top employers + strongest source.
8. Replay historyReplay history of [Company]. Pull all Events for the App ID sorted by Timestamp. Render as a timeline.
9. Profile audit (quarterly)Audit my LinkedIn and résumé via the profile-audit skill. Grade by category, flag red flags (especially "currently unemployed" signaling), produce a prioritized fix list. If I have a gap, recommend specific consulting paths I could legitimately start. Write a Note Added event.
10. Look-alike analysis (per role, refresh ~6mo)Run a look-alike analysis on my target role via the look-alike-analysis skill. Sample 12-20 LinkedIn profiles of people who recently got the role (bias to 6-24 months in role). Identify patterns appearing in 60%+ of sample — skills, certs, headline structure, About conventions, career path. Anonymize subjects. Output a gap analysis: what I have vs. what's common. Log to Look-Alike Analysis tab. Write a Look-Alike Analysis event.

Never Let Claude Do This

  • Click Submit, Send, or Confirm on any application or message — ever.
  • Send a LinkedIn message or email without you reviewing and pressing Send.
  • Modify a past Event row. Events are immutable. Wrong event → write a corrective event, never edit.
  • Update Applications.Status without writing a Status Changed event. The Dashboard breaks if this happens.
  • Delete rows from Events. The history is the system.
  • Use credentials for banking, brokerage, or healthcare apps. Block these in Cowork settings.
  • Bypass a captcha or login wall. If it hits one, it pauses. That's correct.
  • Guess at EEO / work auth / sponsorship answers. If profile is blank, it asks.

Troubleshooting

  • Applications.Status doesn't match latest Status Changed event. Drift. Ask Cowork: "Rebuild Applications status column from Events." Don't manually patch.
  • Last Event Date column is blank. The MAXIFS formula can't find any events for that App ID. Likely a missing Discovery Found event — add one with a backdated timestamp + note "Reconstructed from Applications row."
  • Hit a Pro usage limit. Pro caps come fast when Chrome is running. Wait for reset, or upgrade to Max for heavy weeks. Run discovery-only sessions (no form-fills) on tight days.
  • Cowork can't see Chrome. Re-pair Claude in Chrome from Cowork → Settings → Connectors.
  • Tracker has duplicate Applications rows. Ask Cowork: "Dedupe Applications by Posting URL. Merge sources. Write a Manual Edit event for each merge."
  • Cover letters sound robotic. Edit the cover-letter skill. Add 2-3 of your real letters as examples.
  • An ATS broke mid-fill. Status stays Found, NOT Drafted. A Note Added event is written. Come back manually.
